Lossless compression toolkit

Compression with a C edge.

cPresser combines Delta XOR, RLE, Huffman, and LZ77 into a compact command-line tool that tests each stage and keeps only the transformations that make the file smaller.

Lean where it counts.

Built for a simple job: compress files, preserve every byte, and avoid wasting space on stages that do not improve the output.

Selective

Applies only useful algorithms

Each compression step is measured before it becomes part of the final output.

Portable

CMake-backed C project

A small native codebase with straightforward build requirements: GCC or Clang and CMake.

Recoverable

Headers store the recipe

The compressed file records which stages ran, so decompression can reverse the pipeline automatically.

The pipeline.

Four classic algorithms work together, each targeting a different pattern in the input data.

1

Delta XOR

Stores byte-to-byte changes to reduce repeated structure in gradual data.

2

RLE

Collapses repeated runs into compact count/value pairs.

3

Huffman

Uses shorter codes for frequent symbols and longer codes for rare ones.

4

LZ77

Replaces repeated patterns with references to earlier data windows.

Run it from the terminal.

The interactive CLI keeps the surface area small: choose an action, enter a filename, and let cPresser write the result.

session 
Welcome to cPresser!

Compress (c), Decompress (d), or Exit (x): c
Enter filename: myfile.txt
Success! Output written to 'myfile.txt.cPressed'

Compress (c), Decompress (d), or Exit (x): d
Enter filename: myfile.txt.cPressed
Success! Output written to 'myfile.txt.cPressed.original'

What you need

  • C compiler such as GCC or Clang
  • CMake 3.16 or newer
  • A file you want compressed losslessly
