Lossless compression in C

cPresser

cPresser tries Delta XOR, run-length encoding, Huffman coding, and LZ77. A stage is kept only when it reduces the file size.

View source → Download ZIP

Build

Requires a C compiler and CMake 3.16 or newer.

git clone https://github.com/shahyaranfaz/cPresser.git
cd cPresser
cmake -S . -B build
cmake --build build

Compress and decompress

Start cPress and choose an action from the prompt. Compressed files receive the .cPressed suffix; restored files receive .original.

Compress

./build/cPress

Compress (c), Decompress (d), or Exit (x): c
Enter filename: myfile.txt
Success! Output written to 'myfile.txt.cPressed'

Decompress

Compress (c), Decompress (d), or Exit (x): d
Enter filename: myfile.txt.cPressed
Success! Output written to 'myfile.txt.cPressed.original'

How it works

The output header records which stages were used, so decompression can reverse them automatically.

  1. Delta XOR
  2. Run-length encoding
  3. Huffman coding
  4. LZ77

cPresser processes complete files in memory. The practical file-size limit depends on available memory.
