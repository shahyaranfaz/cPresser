About

cPresser is a powerful file compression tool written in C that intelligently combines multiple compression algorithms to achieve optimal file size reduction. It automatically selects and applies the best combination of compression techniques for your data.

✨ Key Features

🔄

Multi-Algorithm

Combines Delta, RLE, Huffman, and LZ77 compression

🧠

Smart Optimization

Only applies algorithms that reduce file size

⚡

High Performance

Optimized C implementation for speed

💯

Lossless

Perfect reconstruction of original files

📦

Large Files

Handles files up to 1GB

🖥️

Easy CLI

Simple command-line interface

🚀 Quick Start

# Clone the repository
git clone https://github.com/shahyaranfaz/cPresser.git
cd cPresser

# Build the project
mkdir build && cd build
cmake ..
make

# Run cPresser
./cPress

📖 Usage

cPresser provides an interactive interface:

Welcome to cPresser!

Compress (c), Decompress (d), or Exit (x): c
Enter filename: myfile.txt
Success! Output written to 'myfile.txt.cPressed' (1234 bytes, 0.045 seconds)

🔧 Compression Algorithms

Delta (XOR) Encoding

Reduces redundancy by storing XOR differences between consecutive bytes, ideal for data with gradual changes.

Run-Length Encoding

Compresses sequences of repeated bytes efficiently. Perfect for data with long runs of identical values.

Huffman Coding

Variable-length encoding based on symbol frequency. Assigns shorter codes to common symbols.

LZ77 Compression

Dictionary-based compression that finds and replaces repeated patterns with references.

📊 How It Works

cPresser uses an intelligent pipeline approach:

  1. Reads the input file into memory
  2. Tests each compression algorithm sequentially
  3. Keeps only algorithms that reduce file size
  4. Stores compression settings in the output file header
  5. Writes the compressed data with .cPressed extension

During decompression, cPresser reads the header and applies the reverse algorithms in the correct order to perfectly reconstruct the original file.
