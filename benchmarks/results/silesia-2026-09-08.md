## Method

- Source: [Silesia corpus mirror](https://github.com/yewq/Silesia-compression-corpus), preserving the corpus defined by Sebastian Deorowicz.
- Corpus validation: exact published byte size for each of the 12 files; 211,938,580 bytes total.
- Build: CMake Release configuration, GCC 13.2.0, `CPRESS_LZ77_MAX_CHAIN=32`.
- Platform: 64-bit Windows.
- Timing: wall-clock process time measured by Python's `time.perf_counter`; timings include CLI process startup and file I/O.
- Integrity: SHA-256 equality between every source file and its decompressed output.
- Command: `python benchmarks/benchmark_silesia.py build/cPress.exe`.
